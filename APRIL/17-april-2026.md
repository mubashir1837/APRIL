# Scope and Lifetime of Variables in C++

## Introduction

In C++, variables are the basic building blocks of any program. Every variable has two important properties:

- **Scope**: Defines where a variable can be accessed in a program.
- **Lifetime**: Defines how long a variable exists in memory during program execution.

Understanding scope and lifetime helps in writing efficient, bug-free, and memory-safe programs.

---

# 1. Scope of Variables

## Definition

Scope refers to the region of a program where a variable is visible and can be used.

If a variable is outside its scope, it cannot be accessed and will cause a compilation error.

---

# Types of Scope in C++

## 1.1 Local Scope

### Definition
A variable declared inside a function or block is called a local variable. It is only accessible within that function or block.

### Example
```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 10;   // local variable
    cout << x;
    return 0;
}

```


###  Explanation

The variable x can only be used inside the main() function.

### 1.2 Global Scope
 ## Definition

A variable declared outside all functions is called a global variable. It can be accessed from any function in the program.

### Example

```cpp
#include <iostream>
using namespace std;

int x = 50;   // global variable

void display() {
    cout << x;
}

int main() {
    display();
    return 0;
}

```

### Explanation

The variable x is accessible in both display() and main() functions.

### 1.3 Block Scope
## Definition

A variable declared inside a block { } is only accessible within that block.

### Example


```cpp
#include <iostream>
using namespace std;

int main() {
    {
        int y = 5;
        cout << y;
    }

    // cout << y; // Error: y is not accessible here
}

```

### Explanation

The variable y exists only inside the block and cannot be accessed outside it.

### 2. Lifetime of Variables
## Definition

Lifetime refers to the duration for which a variable remains in memory during program execution.

A variable is created when memory is allocated and destroyed when memory is released.

### Types of Lifetime in C++
#### 2.1 Local Variable Lifetime
## Definition

Local variables are created when a function is called and destroyed when the function ends.

### Example

```cpp
#include <iostream>
using namespace std;
void test() {
    int a = 10;  // created
} // destroyed here

```

### Explanation

The variable a exists only during the execution of test() function.

### 2.2 Global Variable Lifetime
## Definition

Global variables are created when the program starts and destroyed when the program ends.

### Example

```cpp
#include <iostream>
using namespace std;

int x = 100;

int main() {
    cout << x;
    return 0;
}

```
### Explanation

The variable x remains in memory throughout the program execution.

2.3 Static Variable Lifetime
Definition

A static variable retains its value between function calls and exists until the program terminates.

### Example

```cpp
#include <iostream>
using namespace std;

void counter() {
    static int c = 0;
    c++;
    cout << c << endl;
}

int main() {
    counter();
    counter();
    counter();
    return 0;
}

```

```shell
Output
1
2
3
Explanation

```

The variable c is initialized only once and retains its value between function calls.

### 3. Scope vs Lifetime Comparison
Feature	Scope	Lifetime
Meaning	Where variable can be accessed	How long variable exists in memory
Focus	Accessibility	Memory duration
Example	Local, Global, Block	Function duration, program time
### 4. Summary
Scope defines where a variable can be used.
Lifetime defines how long a variable stays in memory.
Local variables have limited scope and lifetime.
Global variables have wide scope and long lifetime.
Static variables maintain their value throughout program execution.
### 5. Key Insight

Scope controls accessibility, while lifetime controls memory existence. Both are essential for efficient programming and memory management in C++.
